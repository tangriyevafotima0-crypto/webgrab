# WebGrab — URL to Word Document Compiler

A responsive, client-side web application designed to extract and sanitize content from online articles and serialized fiction, compiling them directly into formatted Microsoft Word (.doc) documents.

## Architectural Highlights
- **Client-Side Document Compilation:** In-browser DOM parsing and conversion generating `.doc` exports without requiring server-side compute.
- **Content Sanitization:** Strips unwanted web boilerplate, advertisements, and formatting noise while preserving document hierarchy.
- **Zero-Dependency Architecture:** Self-contained single-page application built with modern vanilla JavaScript and CSS variables.
- **Instant Cloud Deployment:** Optimized for static hosting via GitHub Pages.

## Usage
Simply enter the target URL into the interface, verify the parsed preview, and trigger the compilation to download the structured document.
